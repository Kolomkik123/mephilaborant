# Расчётчик физического практикума

Стартовая версия командного проекта: самостоятельный расчётчик из папки
`Music/mephilaborant`. Поисковик другого участника пока не подключён;
его интеграция будет отдельным изменением.

В этой версии реализован один агент — расчётчик. Встроенный поиск BM25
нужен ему для выбора формул из PDF и не является поисковиком другого участника.

`src/app/config.py` содержит настройки расчётчика: папки с методичками и
результатами, поиск, лимит обращений и подключение внешних моделей.
`LLM_MODEL` и `LLM_VISION_MODEL` — имена моделей провайдера для работы с текстом
и фото. Сам расчёт выполняется средствами Python. Секреты хранятся в локальной
`.env`; в репозитории есть только пример настроек без ключей.

## Возможности

- Таблицы измерений текстом или фотографией (для фото нужна модель зрения).
- Повторные измерения, погрешности, проверка единиц и линейный МНК.
- Поиск формул в локальных PDF с текстовым слоем, ссылки на страницы.
- Графики и выгрузка результата в JSON, интерфейс Streamlit и API FastAPI.

## Установка и запуск

Нужен Python 3.12. Откройте терминал в папке скачанного репозитория:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe run.py setup
.\.venv\Scripts\python.exe run.py check
.\.venv\Scripts\python.exe run.py ui
```

Откройте http://127.0.0.1:8501. Выберите ввод текстом для проверки без ключей.
Команда `run.py up` запускает интерфейс вместе с API; `run.py demo` — консольный пример.

Без методички формулу можно указать явно. Пример: режим «Повторные измерения»,
задание `формула g = 4*pi**2*L/T**2` и на следующей строке `L = 1 м`.
Таблица:

```text
T, с
2.00
2.01
1.99
2.02
1.98
```

Ожидаемое значение: `g ≈ 9.87 м/с²`. Для автоматического поиска создайте
папку `data/methodics`, положите в неё разрешённые к использованию PDF,
укажите `INDEX_BACKEND=bm25` в `.env` и выполните `run.py index`.
Включён только синтетический демонстрационный PDF из исходного проекта — это
не официальная методичка НИЯУ МИФИ. Остальные PDF, ключи, модели и локальная
среда в репозиторий не включаются.

## Ограничения

Числа считает Python. Распознавание фотографий зависит от внешнего провайдера
и его доступности; настройки задаются только в локальной `.env`.
В режиме `mock` распознавание фото недоступно. Формулы-картинки внутри PDF
пока не распознаются. Распознанные значения нужно сверять с журналом.

Подробности расчётов и ограничений: [README_TEST_RU.md](README_TEST_RU.md).
Раздел запуска на конкретном компьютере в этом документе относится к исходной
локальной папке; после скачивания используйте инструкцию установки выше.

## Работа команды

Первый коммит сохраняет уже существующий расчётчик. Далее каждый участник
добавляет свой модуль в отдельной ветке и описывает изменения в pull request.
Интеграцию поисковика и другие улучшения оформляем отдельными реальными изменениями.
Даты коммитов отражают время сохранения изменений в Git.
