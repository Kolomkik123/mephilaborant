1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10+. Создайте виртуальное окружение и установите библиотеки:

python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt

2. Подготовка данных
Положите все PDF-файлы с методичками в папку data/raw/.
(Внимание: файлы-сканы без текстового слоя не поддерживаются, нужен OCR).

3. Парсинг методичек
Запустите скрипт для извлечения текста(parse_manuals.py)

В папке parsed появятся JSON-файлы.

4. Сборка базы данных
Запустите индексацию (создастся папка data/index/):

python build_index.py
Примечание: Сейчас для локального тестирования используется легковесная модель all-MiniLM-L6-v2 (размерность векторов 384). После получения ключей Cloud.ru она будет заменена на Qwen3-Embedding-0.6B.

5. Тестирование поиска
Проверьте, что база работает(test_search.py)
