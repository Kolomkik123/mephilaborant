## Воспроизведение

После установки зависимостей выполните search-model, search-ocr-model,
search-index, check, search-test через python run.py. Для численных проверок
используйте комплектный демонстрационный PDF без других работ с теми же номерами.
Локальные подробные отчёты: artifacts/metrics.json и artifacts/team_search_report.json.
Модели и готовые базы не публикуются; инструкции их подготовки — в README_LOCAL_SEARCH_RU.md.
