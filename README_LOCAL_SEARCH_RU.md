# Поисковик команды и расчётчик

Исходник SON-12-12-2007 сохранён в modules/manual_search из коммита f58b5a7 ветки feature/search. Приложение использует адаптацию src/app/team_search. Архивный build_index.py не запускайте в корне: он удаляет свой data/index. Другие модули ветки в интеграцию не включены.

## Установка

После установки requirements.txt в Python 3.12 выполните из корня:

```powershell
python run.py search-model
python run.py search-ocr-model
python run.py search-index
python run.py ui
```

Первые две команды требуют интернета. PDF кладите в data/methodics. В интерфейсе выберите «Поисковик команды». Для прежнего поиска выберите «Встроенный BM25»; для API задайте RETRIEVAL_BACKEND=legacy в .env и перезапустите приложение. Старую базу строит python run.py index.

## Устройство

PDF → текст/OCR → data/team_parsed → MiniLM/Chroma в data/team_index → формула → расчётчик Python.

Неизменённые PDF не распознаются повторно: кэш проверяется по контрольной сумме PDF, версии парсера и OCR-моделей. Обновление запускается кнопкой «Обновить базу PDF» или search-index. Неизменённый индекс используется повторно. Новая коллекция становится активной только после успешной сборки. Удалённые PDF исключаются при обновлении; при полностью пустой папке старая база сохраняется.

Во время расчёта PDF не сканируется. Поиск и OCR локальны. Фото измерений обрабатываются отдельно внешней моделью по настройкам расчётчика.

Сохранены MiniLM, Chroma, фрагменты 1000/150 и интерфейс search_manuals(query, work, k). Добавлены явная cosine-метрика, страницы и источники, строгий фильтр по работе, кэш, OCR, заголовки «Р а б о т а» и отделение оглавления. MiniLM запускается через ONNX без PyTorch/LangChain. OCR: tesseract-ocr/tessdata_fast, версия 4.1.0, rus+eng.

## Проверка

```powershell
python run.py check
python run.py search-test
```

check проверяет расчётчик и кэш без внешних моделей. search-test проверяет реальные MiniLM/Chroma, расчётчик, API и интерфейс по демонстрационной базе. Перед search-test выполните search-index на комплектном образце; дополнительные PDF с теми же номерами работ могут менять результат. Отчёты сохраняются в artifacts.

## Ограничения

Комплектный PDF синтетический, не официальная методичка МИФИ. Русский семантический поиск иногда ставит оглавление выше нужного текста; желательно указывать номер работы. OCR не гарантирует правильное чтение дробей и индексов. Сложные формулы Воронова требуют сверки с оригиналом. Одинаковые номера работ из нескольких PDF могут быть неоднозначны. Проверки не доказывают точность на любых реальных работах.
